# 📣 홍보글 공장

학원 **인스타그램 게시물(본문 · 해시태그 · 카드뉴스 그림 · 릴스 대본)** 과 **블로그 글**을 만들어 주는 프로그램입니다.
문제 공장처럼 학원 서버에 붙어 있고, PC에서 따로 켤 수도 있습니다.

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| **학원 정보** | 학원 이름 · 지역 · 과목 · 강점 · 연락처 · 늘 붙일 해시태그 · 예전 글(말투 따라 쓰기)을 한 번 적어 두면 모든 글에 반영 |
| **과목별 글** | 학원 정보에 과목을 `국어, 수학, 영어`처럼 적으면, 글마다 과목(또는 학원 전체)을 고를 수 있음. 과목별 소개를 적어 두면 그 과목 글에만 반영하고, 해시태그 · 블로그 제목 · 카드뉴스 아래 이름에도 과목이 들어감. 보관함과 올릴 거리 추천도 과목별로 |
| **새 글 만들기** | 인스타 / 블로그 / 둘 다 고르고, 글 종류(학원 소개 · 모집 · 공부 팁 · 시험 대비 · 후기 · 특강 · 일상 · 입시 정보 · 학부모 안내 · 공지)와 주제, 메모를 적으면 완성 |
| **인스타그램** | 첫 줄이 눈에 띄는 본문, 해시태그 15~25개(지역+과목 태그 포함, 30개 넘지 않게), 카드뉴스 1~10장, 사진 아이디어, 릴스 대본(고르면) |
| **카드뉴스 그림** | 인스타 세로 비율(1080×1350) PNG로 바로 만들어 줌. 색 5가지. 한 장씩 또는 ZIP으로 받기 |
| **블로그** | 제목 후보 3개, 검색 키워드, 소제목 · 사진 넣을 자리까지 정리된 본문, 태그. '네이버 블로그용 복사'를 누르면 소제목이 살아 있는 채로 붙여 넣어짐 |
| **올릴 거리 추천** | 이번 달 학원가 일정(시험 · 방학 · 모의고사)과 최근 올린 글을 보고 글감 8개 추천 → '이걸로 쓰기' |
| **말로 고치기** | "더 짧게", "학부모 대상으로", "카드 3장에 첨삭 이야기 넣어 줘" 처럼 적으면 AI가 고침 |
| **직접 고치기 · 되돌리기 · 새로 쓰기** | 손으로 고쳐 저장하거나, 한 단계 되돌리거나, 같은 주제로 처음부터 다시 |

### 올리기 전에 알려 주는 것
- **과장 광고 말**: '합격 보장', '100%', '1등 학원', '최초' 같은 말이 있으면 표시합니다. '쓰지 말았으면 하는 말'에 적은 말도 찾아 줍니다.
- **채울 빈칸**: AI가 모르는 정보는 지어내지 않고 `[개강일]`처럼 빈칸으로 남기고, 빈칸 목록을 보여 줍니다.
- **등록번호 · 교습비**: 모집 · 소개 · 후기 · 이벤트 글에는 학원 등록번호와 교습비를 적어야 할 수 있습니다(학원법).
  학원 정보에 적어 두면 그런 글 끝에 자동으로 붙이고, 비어 있으면 알려 줍니다.
- 학생 이름 · 학교 이름은 쓰지 않도록 AI에게 지시합니다(후기는 '고2 ○○ 학생'처럼).

## 학원 서버(Render)에서 쓰기
따로 할 것은 없습니다. 서버가 배포되면 **학원 서버 주소 뒤에 `/sns/`** 로 들어가면 됩니다
(예: `https://학원서버.onrender.com/sns/`). 로그인은 문제 공장과 같습니다(관리자 이름 · 비밀번호, 이름을 비우면 원장님).
자료는 Firestore의 `sns_` 로 시작하는 컬렉션에 저장됩니다. AI 키는 서버의 `GOOGLE_API_KEY`를 그대로 씁니다.

## PC에서 따로 켜기
```bash
pip install -r question_maker/requirements.txt Pillow
```
```bash
python -m sns_maker
```
브라우저가 열립니다(안 열리면 http://127.0.0.1:8810). 키 없이 둘러보려면 `SNS_DEMO=1`을 넣고 켜세요.

| 환경 변수 | 뜻 | 기본값 |
|---|---|---|
| `GOOGLE_API_KEY` | Gemini API 키 (`GEMINI_API_KEY`도 됨) | — |
| `SNS_DB` | 자료 파일 | 지금 폴더의 `sns_maker.db` |
| `SNS_PORT` / `SNS_HOST` | 주소 | `8810` / `127.0.0.1` |
| `SNS_PASSWORD` | 정하면 들어올 때 비밀번호를 물음 (인터넷에 올릴 때 필수) | 없음 |
| `SNS_DEMO` | `1`이면 연습용 AI | — |

## 개발자용
```bash
python -m pytest sns_maker/tests
```
- `catalog.py` 글 종류 · 말투 · 달마다 학원가 일 · 과장 광고 말 목록
- `generator.py` 프롬프트, AI 답 확인, 등록번호 꼬리말, 올리기 전 확인
- `cards.py` 카드뉴스 PNG (저장소의 `fonts/NotoSansKR.ttf` 사용)
- `storage.py` SQLite / Firestore 저장
- `app.py` 웹 서버, `static/index.html` 화면
- AI 연결은 `question_maker/ai.py`의 Gemini 연결을 그대로 씁니다.
