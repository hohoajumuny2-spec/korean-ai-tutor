# 📝 문제 공장

지문을 주면 원하는 **난이도 · 종류 · 유형 · 스타일**로 문제를 만들어 두는 프로그램입니다.
학원 앱과는 따로 돌아가는 독립 프로그램이며, 자료는 파일 하나(`question_maker.db`)에 저장됩니다.

## 할 수 있는 것

| 기능 | 설명 |
|---|---|
| **원할 때 출제** | '새로 출제'에 지문을 붙여넣고(또는 txt·pdf·사진에서 불러오고) 바로 출제 |
| **매일 자동 출제** | 지문을 '보관함'에 쌓아 두면, 정한 시각·요일에 위에서부터 정한 개수만큼 꺼내 문제를 만들어 둠 |
| **난이도** | 킬러 · 준킬러 · 상 · 중 · 하 (기존 학원 서버의 출제 원칙 그대로) |
| **문제 종류** | 객관식(4지·5지) · 단답형 · 빈칸 채우기 · OX — "객관식 상 3개, OX 하 5개"처럼 줄마다 정함 |
| **문제 유형** | 사실적 이해, 추론, 비판, 적용([보기]), 시어의 의미, 표현상 특징 등 고르거나 직접 적기 → 문항마다 골고루 나눔 |
| **스타일 저장** | 선지 수, 부정 발문 비율, ㉠·ⓐ·[A] 기호와 밑줄, 해설 길이, 발문 말투 예시, 원장님 지침, 시험지 모양(제목·학원 이름·1단/2단·글꼴·글자 크기·이름 칸)을 이름 붙여 저장 |
| **시험지 출력** | 실제 시험지 모양 → 인쇄 또는 'PDF로 저장'. 시험지만 / 해설만 / 둘 다. 여러 세트를 한 시험지로 묶기 |
| **말로 고치기** | "3번 더 어렵게", "5번 선지 ④를 더 헷갈리게", "OX 2개 더" 처럼 적으면 AI가 고침 |
| **직접 고치기** | 문항마다 '편집'으로 발문·선지·정답·해설을 손으로 고치거나 문항 빼기 |
| **되돌리기** | 고치기·다시 출제 전 상태가 쌓여 있어 언제든 한 단계씩 되돌림 |

### 품질을 지키는 장치
- **검수**: 만든 뒤 AI가 한 번 더 지문과 대조해 오채점·정답이 둘인 문항·티 나는 정답 선지를 고칩니다(끌 수 있음).
- **지문 보호**: AI가 지문 문장을 몰래 바꿔 쓰면 알아채고 원본 지문을 그대로 싣습니다.
- **정답 번호 고르게**: 객관식 정답 번호가 ③에 몰리거나 규칙적으로 나오지 않게, 프로그램이 정답 선지 자리를 바꿔 고르게 퍼뜨립니다(선지별 해설도 함께 옮김).
- **형식 확인**: 선지 수가 틀리거나 정답이 없는 문항은 걸러내고, 빠진 문항은 한 번 더 요청합니다.

## 켜는 법

### 1. 준비 (처음 한 번)
파이썬 3.10 이상이 필요합니다. 이 저장소 폴더에서:

```bash
pip install -r question_maker/requirements.txt
```

### 2. AI 키 넣기
학원 서버에서 쓰는 것과 같은 구글 Gemini 키(GOOGLE_API_KEY)를 씁니다.

- 윈도우(명령 프롬프트): `set GOOGLE_API_KEY=여기에키`
- 맥/리눅스: `export GOOGLE_API_KEY=여기에키`

### 3. 켜기
```bash
python -m question_maker
```
브라우저가 자동으로 열립니다. 안 열리면 http://127.0.0.1:8800 으로 들어가세요.

> 키 없이 화면만 둘러보려면 `QM_DEMO=1` 을 넣고 켜세요. 지문을 읽지 않은 가짜 문제가 만들어집니다.

### 매일 출제에 대해
매일 출제는 **프로그램이 켜져 있을 때** 동작합니다. 정한 시각에 컴퓨터가 꺼져 있었다면, 그날 나중에 켜는 순간 바로 출제합니다(하루 한 번).
매일 켜 두기 어렵다면 학원 서버처럼 늘 켜져 있는 곳(클라우드)에 올려 두세요. 이때는 아래 `QM_PASSWORD`를 꼭 정하세요.

## 설정 (환경 변수)

| 이름 | 뜻 | 기본값 |
|---|---|---|
| `GOOGLE_API_KEY` | Gemini API 키 (`GEMINI_API_KEY`도 됨) | — |
| `QM_DB` | 자료를 저장할 파일 | 지금 폴더의 `question_maker.db` |
| `QM_PORT` / `QM_HOST` | 주소 | `8800` / `127.0.0.1` |
| `QM_PASSWORD` | 정하면 들어올 때 비밀번호를 물음 (인터넷에 올릴 때 필수) | 없음 |
| `QM_MODEL` / `QM_FAST_MODEL` | 출제용 / 검수·글 옮기기용 모델을 직접 고를 때 | 자동 선택 |
| `QM_DEMO` | `1`이면 연습용 AI | — |

## 백업
`question_maker.db` 파일 하나만 복사해 두면 지문·문제·스타일·설정이 모두 보관됩니다.

## 개발자용
```bash
pip install pytest httpx
python -m pytest question_maker/tests
```
- `catalog.py` 종류·난이도·유형 목록과 기본값
- `generator.py` 프롬프트, AI 답 확인, 검수, 말로 고치기
- `render.py` 시험지 HTML
- `storage.py` SQLite 저장
- `app.py` 웹 서버와 매일 출제 스케줄러
- `static/index.html` 화면
